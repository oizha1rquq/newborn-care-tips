# 【医学日历】世界肥胖日：让我们谈谈肥胖和……

> 更新时间：2026-09-17 (UTC+8)

如今，肥胖已经成为全球性的公共卫生问题。为倡导全球各国关注，采取有效措施预防控制人群超重和肥胖，世界肥胖联盟（World Obesity Federation, WOF）于2020年宣布将每年的3月4日确定为“世界肥胖日”。

2024年世界肥胖日的主题为“让我们谈谈肥胖和……”（LET'S TALK ABOUT OBESITY AND...）。

实际上，大多数“胖友”都有自己的“减肥梦”，却往往无法实现，只能连连摆手，用“减肥太‘简单’了！我个人就减了很多次……”这样的话自嘲一番，表示自己对该话题已不愿多谈。小编就是如此，与各位“胖友”一样无奈！

so，小编今天特地邀请了广西国际壮医医院内分泌代谢病科副主任胡璟，与大家聊聊肥胖发热危害，以及有效预防、治疗肥胖的方法。

**肥胖科普问答**

**肥胖的危害是什么？**

除身材走形外，肥胖还会导致糖尿病、心血管疾病、高血压、癌症（如乳腺癌、大肠癌）、打呼噜等，并影响患者心理健康，增加抑郁和焦虑的风险。

**如何确定自己是否肥胖？**

判断肥胖最常用的方法是体质指数（BMI），即体重（公斤）除以身高（米）的平方。

**成年人的BMI标准：**18.5—23.9为正常体重，24—27.9为超重，28及以上为肥胖，30及以上为重度肥胖。

除BMI外，腰围的测量也是评估肥胖及其健康风险的重要指标，因为腹部脂肪堆积更可能引起健康问题，男性腰围≥90cm、女性腰围≥85cm即可认为存在腹型肥胖。

有一部分体型正常、体重达标的人则是“深藏不露的胖子”，他们的脂肪大多分布在腹腔中的肝、胰、脾、胃、肠等脏器周围，所以除了计算BMI，我们还需要综合测量自己的腰、臀围和体脂率（成年男性体脂率一般为10%-20%，成年女性体脂率一般为18%-28%）。

**肥胖是什么原因导致的？**

肥胖是一种由多种因素引起的慢性代谢性疾病。由于长期能量摄入过多，超过机体能量消耗，体内多余能量转化为脂肪，并过多积聚而引起营养代谢失衡。95%的肥胖是单纯性肥胖，为遗传因素、不良生活习惯、失眠、心理状态等导致，饮食是大多数人肥胖的直接原因。剩余5%的肥胖则是继发于某些内分泌疾病或药物，如多囊卵巢综合征、甲状腺功能减退症、库欣综合征、肢端肥大症、长期应用糖皮质激素、抗精神类药物等，必须通过治疗原发疾病改善肥胖问题。

**如何预防肥胖？**

**科学饮食：**增加蔬菜和全谷物的摄入，减少加工食品和高糖饮料的摄入，规律饮食，避免摄入过多能量。

**坚持有规律的运动：**每周至少进行150分钟的中等强度运动，如快走、游泳或骑自行车等。

**保证良好睡眠：**保证每晚7至9小时的高质量睡眠。

**缓解压力：**采用冥想、瑜伽等方式管理生活中的压力。

**中壮医治疗：**可以采用中壮药内服、中壮医外治等方法调理脾胃、疏肝解郁、化痰祛湿来预防肥胖。

**怎么才能正确减重？**

建议肥胖，尤其重度肥胖患者，或通过单纯饮食、运动控制而减重效果不理想的小伙伴，应尽快寻求专科医生的帮助。因为这表示减肥方案存在缺陷，或意味着肥胖是某些疾病继发，需由医生检查，科学评估身体情况后合理制定减重方案，否则盲目减肥不但伤身还可能耽误病情。

**减重方法如下：**

**个性化饮食计划：**根据患者个人情况制定合理的饮食计划，避免极端或单一的饮食方式，保证饮食营养健康、热量合理。

**科学的体育运动：**有氧运动能帮助脂肪燃烧，力量训练则能增加肌肉量，提高基础代谢率。

**良好的睡眠习惯：**保证睡眠质量，避免熬夜。

**心理支持：**保持积极的心态，必要时寻求专业心理咨询。

**医学治疗：**于正规医院就诊后，使用辅助减重药物治疗，合并糖尿病的肥胖患者，则可以选择具有减重作用的降糖药治疗。此外，也可使用壮医针灸、药物埋线、拔罐，以及中药内服等中医、民族医疗法调理身体、辅助减重。

需要注意的是，目前市面上所谓的“减肥药物”“减肥产品”大多为非正规产品，具体成分及疗效、副作用不明，应仔细甄别并避免选择这些产品。
